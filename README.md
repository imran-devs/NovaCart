# 🛒 NovaCart

A modern Flutter shopping application built with **BLoC**, **Hive**, and **REST APIs**.

## ✨ Features

- 🛍 Browse Products
- 🔍 Search Products
- ❤️ Wishlist
- 🛒 Shopping Cart
- ➕ Increase/Decrease Quantity
- 📦 Checkout
- 📍 Save Delivery Address
- 💳 Multiple Payment Methods
- ✅ Order Success Screen
- 💾 Offline Storage using Hive
- ⚡ State Management with BLoC/Cubit
- 🌐 REST API Integration
- ✨ Shimmer Loading Effect

---

## 🛠 Built With

- Flutter
- Dart
- flutter_bloc

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/imran-devs/NovaCart.git
```

Install dependencies

```bash
flutter pub get
```

Run the project

```bash
flutter run
```
